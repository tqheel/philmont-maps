# Topographical Map Generation Specification

**Philmont Scout Ranch — Crew 618-J, Itinerary 12-1 (2026)**

---

## Overview

Generate day-by-day topographical maps from KML location data and SRTM elevation rasters using Python, producing printable 8.5×11" maps for each hiking day of Crew 618-J's 12-day South Country trek. Each map shows the day's route, waypoints, campsites, elevation profile, and terrain context — optimized for field navigation and expedition briefings.

---

## 1. Architecture

### 1.1 Data Pipeline

```
KML Input → Parse & Validate → Extract Day N Route → Grid Interpolation →
Terrain Analysis → Layout & Compose (8.5×11") → PDF/PNG Output
```

### 1.2 Core Components

| Module | Responsibility |
|--------|---------------|
| **XML Parser** | Extract location coordinates, elevation, and waypoint metadata |
| **Route Extractor** | Filter points/segments for each individual day |
| **Data Validator** | Ensure data integrity for each day's corridor |
| **Grid Interpolator** | Convert scattered elevation points to regular grid (kriging/IDW) |
| **Terrain Analyzer** | Compute slope, aspect, hillshade for the day's area |
| **Layout Engine** | Compose 8.5×11" page with map, profile, legend, camp notes |
| **Output Handler** | Export to PDF (primary) and PNG formats |

### 1.3 Crew 618-J Specifics

- **Trek:** Itinerary 12-1, South Country, 54 miles total, 12 days
- **Output:** 12 individual day maps + 1 summary/overview map
- **Elevation range:** 6,729 ft (Base Camp) to 9,343 ft (near Beaubien/Tooth of Time)
- **Print target:** Standard 8.5×11" (letter size) with 0.5" margins for binding/annotation
- **Use case:** Field navigation, pre-trek briefing, expedition memory

## 2. Data Structure (PhilTrek KML Input)

### 2.1 KML Format (PhilTrek Schema)

**Source:** `itinerary_1_corrected.kml` (PhilTrek.com, corrected for Crew 618-J)

The KML file contains:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<kml xmlns="http://www.opengis.net/kml/2.2">
  <Document>
    <name>Itinerary Number 1</name>
    <description>KML generated by PhilTrek.com</description>

    <!-- MAIN TREK PATH (CONTINUOUS LINESTRING) -->
    <!-- Single LineString with all 762 coordinate points (lon,lat,elevation) -->
    <!-- Elevation values are 0 in file; use SRTM DEM to populate -->
    <Placemark>
      <name>Path of Itinerary Number 1</name>
      <LineString>
        <coordinates>
          -104.930362,36.365230,0
          -104.930064,36.366952,0
          ... (762 points total)
          -104.962480,36.453513,0
        </coordinates>
      </LineString>
    </Placemark>

    <!-- CAMP WAYPOINTS -->
    <Placemark>
      <name>Start</name>
      <styleUrl>#markerStart</styleUrl>
      <Point><coordinates>-104.930362,36.365230,0</coordinates></Point>
    </Placemark>

    <Placemark>
      <name>Olympia</name>
      <styleUrl>#markerCamp</styleUrl>
      <Point><coordinates>-104.968928,36.371734,0</coordinates></Point>
    </Placemark>

    <Placemark>
      <name>Apache Springs (passthrough)</name>
      <styleUrl>#markerPass</styleUrl>
      <Point><coordinates>-105.144133,36.387479,0</coordinates></Point>
    </Placemark>

    <Placemark>
      <name>End</name>
      <styleUrl>#markerEnd</styleUrl>
      <Point><coordinates>-104.962480,36.453513,0</coordinates></Point>
    </Placemark>
  </Document>
</kml>
```

**Passthrough Locations** (`styleUrl=#markerPass`):

- Crater Lake (Day 9, between Miners Park and Bear Caves)
- RMSC (Day 11, ~1 mi off-path detour for COPE program)

**Trailheads** (`styleUrl=#markerStart`, `#markerEnd`):

- Start: Rayado Trailhead (36.365230, -104.930362)
- End: Base Camp (36.453513, -104.962480)

### 2.3 Known Issues in KML Data

| Day | Issue | Impact | Mitigation |
|-----|-------|--------|------------|
| 8 | Duplicate path removed (corrected) | Original: 15.55 mi → Fixed: 8.23 mi | Use corrected KML; official says 8.6 mi |
| 10 | Route variant mismatch | KML: 5.50 mi vs. Official: 4.6 mi (+0.9 mi) | Use official 4.6 mi for planning |
| 11 | RMSC detour not in path | KML: 3.64 mi vs. Official: 4.7 mi (-1.06 mi) | KML skips RMSC; add ~1 mi for detour in notes |

### 2.4 Parser Requirements

The KML parser must:

1. Extract all Placemarks, classified by `styleUrl` (camps, passthrough, trailhead)
2. Extract continuous LineString path (762 coordinates)
3. Snap camp/passthrough points to nearest path coordinate
4. Split continuous path into day segments based on camp waypoint sequence
5. Calculate distance along path for each segment (haversine)
6. Assign elevations from SRTM DEM (KML has no elevation data)
7. Validate camp sequence: `Start → Olympia → Abreu → ... → End`

**Error handling:**

| Condition | Action |
|-----------|--------|
| Malformed KML | Explicit error with line numbers |
| Missing Placemarks | Warn and skip |
| Invalid coordinates | Skip with logging |
| Waypoint snap distance > 0.1 mi | Warn (path/marker mismatch) |
| Missing SRTM data | Error (required) |

**Known discrepancies to handle:**

- Day 10: Use official 4.6 mi, not KML's 5.50 mi
- Day 11: KML shows 3.64 mi; add ~1 mi RMSC detour → 4.6–4.7 mi total
- Day 8: Use corrected KML (8.23 mi); within 4% of official 8.6 mi

### 2.5 Python KML Parsing Example

```python
import xml.etree.ElementTree as ET
import numpy as np

class KMLParser:
    """Parse PhilTrek KML format."""

    def __init__(self, kml_path):
        self.kml_path = kml_path
        self.tree = ET.parse(kml_path)
        self.root = self.tree.getroot()
        self.ns = {'kml': 'http://www.opengis.net/kml/2.2'}

    def extract_path(self):
        """Extract continuous LineString path."""
        linestring = self.root.find('.//kml:LineString/kml:coordinates', self.ns)
        coords_text = linestring.text.strip()

        path = []
        for coord in coords_text.split('\n'):
            lon, lat, elev = coord.split(',')
            path.append({
                'lon': float(lon),
                'lat': float(lat),
                'elev': float(elev),  # Will be 0 in raw KML
                'index': len(path)
            })
        return path

    def extract_waypoints(self):
        """Extract camp and passthrough placemarks."""
        waypoints = {}
        placemarks = self.root.findall('.//kml:Placemark', self.ns)

        for pm in placemarks:
            name = pm.find('kml:name', self.ns).text
            style = pm.find('kml:styleUrl', self.ns).text
            coords_elem = pm.find('.//kml:coordinates', self.ns)

            if coords_elem is not None:
                lon, lat, elev = coords_elem.text.split(',')

                if 'markerStart' in style:
                    wp_type = 'trailhead_start'
                elif 'markerEnd' in style:
                    wp_type = 'trailhead_end'
                elif 'markerCamp' in style:
                    wp_type = 'camp'
                elif 'markerPass' in style:
                    wp_type = 'passthrough'
                else:
                    wp_type = 'poi'

                waypoints[name] = {
                    'name': name,
                    'type': wp_type,
                    'lon': float(lon),
                    'lat': float(lat),
                    'elev': float(elev),
                }

        return waypoints

    def snap_waypoint_to_path(self, waypoint, path):
        """Find nearest point on path to waypoint."""
        min_dist = float('inf')
        best_idx = 0

        for i, pt in enumerate(path):
            dist = self.haversine(waypoint['lat'], waypoint['lon'],
                                  pt['lat'], pt['lon'])
            if dist < min_dist:
                min_dist = dist
                best_idx = i

        return best_idx, min_dist

    @staticmethod
    def haversine(lat1, lon1, lat2, lon2):
        """Distance in miles."""
        R = 3959
        dlat = np.radians(lat2 - lat1)
        dlon = np.radians(lon2 - lon1)
        a = (np.sin(dlat/2)**2
             + np.cos(np.radians(lat1)) * np.cos(np.radians(lat2)) * np.sin(dlon/2)**2)
        return R * 2 * np.arcsin(np.sqrt(a))

    def segment_path_by_camps(self, path, waypoints):
        """Split path into day segments based on camp sequence."""
        # NOTE: passthrough locations (Apache Springs, Black Mountain, Crater Lake)
        # are sub-segments within their respective days, not day boundaries.
        # RMSC is a ~1 mi off-path detour — not in the path index.
        camp_sequence = [
            'Start',
            'Olympia',
            'Abreu',
            'Fish Camp',
            'Buck Creek',
            'Beaubien (layover)',
            'Miners Park',
            'Bear Caves',
            'Urraca',
            'Stockade Ridge',
            'End',
        ]

        path_indices = {}
        for camp_name in camp_sequence:
            if camp_name in waypoints:
                idx, dist = self.snap_waypoint_to_path(waypoints[camp_name], path)
                path_indices[camp_name] = idx

        day_segments = {}
        # Days: Start→Olympia=2, Olympia→Abreu=3, ..., Stockade→End=12
        day_map = {
            ('Start', 'Olympia'): 2,
            ('Olympia', 'Abreu'): 3,
            ('Abreu', 'Fish Camp'): 4,
            ('Fish Camp', 'Buck Creek'): 5,
            ('Buck Creek', 'Beaubien (layover)'): 6,
            # Day 7 is layover — no path segment
            ('Beaubien (layover)', 'Miners Park'): 8,
            ('Miners Park', 'Bear Caves'): 9,
            ('Bear Caves', 'Urraca'): 10,
            ('Urraca', 'Stockade Ridge'): 11,
            ('Stockade Ridge', 'End'): 12,
        }

        for (from_camp, to_camp), day in day_map.items():
            if from_camp in path_indices and to_camp in path_indices:
                start_idx = path_indices[from_camp]
                end_idx = path_indices[to_camp]
                segment = path[start_idx:end_idx + 1]
                dist_miles = sum(
                    self.haversine(segment[j]['lat'], segment[j]['lon'],
                                   segment[j+1]['lat'], segment[j+1]['lon'])
                    for j in range(len(segment) - 1)
                )
                day_segments[day] = {
                    'from': from_camp,
                    'to': to_camp,
                    'path': segment,
                    'distance_miles': dist_miles,
                    'day': day,
                }

        return day_segments
```

### Phase 2: Grid Interpolation *(Priority: High)*

**Deliverable:** Regular elevation grid from SRTM raster, suitable for hillshade and contour rendering.

**Method options:**

| Option | Method | Pros | Cons | Use Case |
|--------|--------|------|------|----------|
| A | IDW (Inverse Distance Weighting) | Fast, simple | "Bulls-eye" artifacts | Quick previews |
| B | `scipy.interpolate.griddata` (cubic) | Reliable, multiple methods | Slower on large datasets | **Recommended for MVP** |
| C | Radial Basis Functions (RBF) | Smooth, mathematically sound | Memory-intensive | Small high-precision regions |
| D | Kriging (`pykrige`) | Statistically optimal | Complex, slow | Research-grade maps |

**Configuration:**

```python
grid_resolution = 100  # points per axis (100x100 = 10,000 cells)
bounds = (min_lon, max_lon, min_lat, max_lat)

grid_x, grid_y = np.meshgrid(
    np.linspace(bounds[0], bounds[1], grid_resolution),
    np.linspace(bounds[2], bounds[3], grid_resolution)
)
elevation_grid = scipy.interpolate.griddata(
    points, values, (grid_x, grid_y), method='cubic'
)
```

### Phase 3: Terrain Analysis *(Priority: Medium)*

**Deliverable:** Derived terrain metrics for visualization enhancement.

| Metric | Formula | Use Case |
|--------|---------|----------|
| Slope | `arctan(sqrt((∂z/∂x)² + (∂z/∂y)²))` | Steepness visualization |
| Aspect | `atan2(∂z/∂y, ∂z/∂x)` | Sun/shadow direction |
| Hillshade | `cos(zenith)*cos(slope) + sin(zenith)*sin(slope)*cos(aspect - azimuth)` | 3D terrain effect |
| Contours | Level sets of elevation | Standard topo lines |

**Libraries:** `scipy.ndimage.sobel` (gradient/slope), `numpy.arctan2` (aspect), `matplotlib.contour` (contour extraction)

### Phase 4: Page Layout & Visualization *(Priority: High)*

**Deliverable:** 8.5×11" printable PDF maps for each day + overview.

#### 4.1 Page Layout (Letter, Portrait)

Each day's map page comprises four zones:

**Header (0.5" h):**
- Left: Expedition number, crew name, date range
- Center: Day number, camp-to-camp route, distance/elevation
- Right: Print date, map scale

**Main Map Area (7.5" w × ~6.5" h):**
- Terrain background (elevation color gradient + hillshade overlay)
- Contour lines every 200–500 ft, thinned for clarity
- Day's route in bold red; previous/next day routes in faded gray
- Camp symbols: `●` staffed, `○` trail, `▼` passthrough
- Scale bar (miles and km), north arrow, coordinate grid (configurable)

**Elevation Profile (full-width, ~1.5" h):**
- X-axis: distance (miles), Y-axis: elevation (ft)
- Area under curve shaded; waypoints marked with symbols
- Gain/loss labels; optional time estimates at 2–3 mph

**Camp Notes Box:**
- Camp name, elevation, type (staffed/trail/dry)
- Key programs, water, facilities
- Tomorrow's distance/gain; equipment reminders

#### 4.3 Matplotlib Code Template

```python
import matplotlib.pyplot as plt
from matplotlib.gridspec import GridSpec
import numpy as np
import datetime

def generate_day_map(day_data, elevation_grid, hillshade_grid, output_path):
    """Generate single 8.5x11 day map."""
    fig = plt.figure(figsize=(8.5, 11), dpi=300, facecolor='white')
    gs = GridSpec(3, 1, height_ratios=[0.5, 5, 1.5], hspace=0.25)

    # ---- HEADER ----
    ax_header = fig.add_subplot(gs[0])
    ax_header.axis('off')
    ax_header.text(0.05, 0.7, "Crew 618-J | Itinerary 12-1",
                   fontsize=10, weight='bold', va='top')
    ax_header.text(0.5, 0.7,
                   f"Day {day_data['day']}: {day_data['camp_from']} → {day_data['camp_to']}"
                   f" ({day_data['distance']:.1f} mi, {day_data['gain']}' gain)",
                   fontsize=12, weight='bold', ha='center', va='top')
    ax_header.text(0.95, 0.7, f"Generated: {datetime.date.today()}",
                   fontsize=8, ha='right', va='top', style='italic')

    # ---- MAIN MAP ----
    ax_map = fig.add_subplot(gs[1])
    extent = [day_data['lon_min'], day_data['lon_max'],
              day_data['lat_min'], day_data['lat_max']]

    ax_map.imshow(elevation_grid, extent=extent, origin='lower',
                  cmap='terrain', alpha=0.85, aspect='auto')
    ax_map.imshow(hillshade_grid, extent=extent, origin='lower',
                  cmap='gray', alpha=0.2, aspect='auto')

    contours = ax_map.contour(elevation_grid, levels=20,
                               colors='#333333', linewidths=0.5, alpha=0.4)
    ax_map.clabel(contours, inline=True, fontsize=7, fmt='%d ft')

    route_lons = [w['lon'] for w in day_data['waypoints']]
    route_lats = [w['lat'] for w in day_data['waypoints']]
    ax_map.plot(route_lons, route_lats, color='#E31C23', linewidth=2.5,
                label=f"Day {day_data['day']} Route", zorder=5)

    if day_data.get('prev_waypoints'):
        ax_map.plot([w['lon'] for w in day_data['prev_waypoints']],
                    [w['lat'] for w in day_data['prev_waypoints']],
                    color='#CCCCCC', linewidth=1, alpha=0.5, zorder=3)

    if day_data.get('next_waypoints'):
        ax_map.plot([w['lon'] for w in day_data['next_waypoints']],
                    [w['lat'] for w in day_data['next_waypoints']],
                    color='#CCCCCC', linewidth=1, alpha=0.5, zorder=3)

    symbol_map = {
        'camp_staffed': ('o', '#FF6B35'),
        'camp_trail':   ('o', '#004E89'),
        'passthrough':  ('v', '#F7B801'),
        'trailhead':    ('^', '#666666'),
    }
    for waypoint in day_data['all_waypoints']:
        marker, color = symbol_map.get(waypoint['type'], ('^', '#666666'))
        ax_map.scatter(waypoint['lon'], waypoint['lat'], s=200, marker=marker,
                       color=color, edgecolors='black', linewidths=1, zorder=10)
        ax_map.annotate(waypoint['name'],
                        xy=(waypoint['lon'], waypoint['lat']),
                        xytext=(5, 5), textcoords='offset points',
                        fontsize=7, weight='bold',
                        bbox=dict(boxstyle='round,pad=0.3', facecolor='white', alpha=0.8))

    ax_map.set_xlabel('Longitude', fontsize=9)
    ax_map.set_ylabel('Latitude', fontsize=9)
    ax_map.set_title(f"Topographic Map — {day_data['camp_from']} to {day_data['camp_to']}",
                     fontsize=11, weight='bold', pad=10)
    ax_map.grid(True, alpha=0.3, linestyle=':', linewidth=0.5)
    ax_map.legend(loc='upper right', fontsize=8, framealpha=0.95)

    # ---- ELEVATION PROFILE ----
    ax_profile = fig.add_subplot(gs[2])
    distances  = np.array([w['distance_from_start'] for w in day_data['waypoints']])
    elevations = np.array([w['elevation'] for w in day_data['waypoints']])

    ax_profile.fill_between(distances, elevations.min() - 500, elevations,
                             color='#70AD47', alpha=0.4)
    ax_profile.plot(distances, elevations, color='#333333', linewidth=2,
                    marker='o', markersize=6,
                    markerfacecolor='#E31C23', markeredgecolor='black', markeredgewidth=1)

    for wp in day_data['waypoints']:
        ax_profile.annotate(wp['name'],
                            xy=(wp['distance_from_start'], wp['elevation']),
                            xytext=(0, 10), textcoords='offset points',
                            ha='center', fontsize=7, weight='bold')

    ax_profile.set_xlabel('Distance (miles)', fontsize=9)
    ax_profile.set_ylabel('Elevation (ft)', fontsize=9)
    ax_profile.set_title(f"Elevation Profile: +{day_data['gain']}' / -{day_data['loss']}'",
                         fontsize=10, weight='bold')
    ax_profile.grid(True, alpha=0.3, linestyle=':', linewidth=0.5)

    plt.tight_layout()
    plt.savefig(output_path, dpi=300, format='pdf', bbox_inches='tight',
                facecolor='white', edgecolor='none')
    print(f"Saved: {output_path}")
    plt.close()
```

#### 4.4 PDF Assembly (Multi-Page Document)

```python
from PyPDF2 import PdfMerger

def generate_all_day_maps(trek_data, output_pdf):
    """Generate all day maps and compile into single PDF."""
    day_pdfs = []
    for day in range(2, 13):
        day_path = f"output/day_{day:02d}.pdf"
        generate_day_map(trek_data[day], day_path)
        day_pdfs.append(day_path)

    merger = PdfMerger()
    for pdf in day_pdfs:
        merger.append(pdf)
    merger.write(output_pdf)
    merger.close()
    print(f"Compiled: {output_pdf}")
```

```python
class MapScale:
    """Handle map scale conversion and display."""

    def __init__(self, scale_string='auto'):
        self.scale_string = scale_string
        self.scale_ratio = self._parse_scale(scale_string)

    def _parse_scale(self, scale_string):
        if scale_string == 'auto':
            return None
        if ':' in scale_string:
            return int(scale_string.split(':')[1])
        return None

    def calculate_scale_for_bounds(self, bounds_latlon, page_width_inches=7.5, dpi=300):
        """Calculate map scale to fit bounds on page. Returns (ratio, label)."""
        lat_range = bounds_latlon[1] - bounds_latlon[0]
        lon_range = bounds_latlon[3] - bounds_latlon[2]
        km_per_lat = 111.0
        km_per_lon = 111.0 * np.cos(np.radians(36.8))  # Philmont ~36.8°N
        max_km = max(lat_range * km_per_lat, lon_range * km_per_lon)
        feet_per_inch = (max_km * 3280.84) / page_width_inches
        scale_ratio = int(feet_per_inch * 12)
        return scale_ratio, f"1:{scale_ratio}"
```

### 12.2 File Format Comparison

| Format | Use Case | Device Support | Size | Elevation |
|--------|----------|---------------|------|-----------|
| GPX (recommended) | Navigation | All Garmin + smartphone apps | 1–5 MB | Yes |
| KML | Google Earth | Google Maps, Google Earth | 1–5 MB | Yes |
| TCX | Fitness tracking | Garmin Fenix, Edge, Forerunner | 0.5–2 MB | Yes |

### 12.3 GPX Variants

| Variant | Command | Size | Best For |
|---------|---------|------|----------|
| Full detail | `--garmin-day-segments --elevation-sample-interval 50` | ~2 MB | Desktop analysis, detailed nav |
| Light/mobile | `--garmin-day-segments --elevation-sample-interval 200 --simplify-track` | ~500 KB | Smartphone, older GPS |
| Single track | *(no `--garmin-day-segments`)* | ~1 MB | Overview, reference |

### 12.4 Garmin Device Compatibility

**Tested:**
- Garmin inReach Mini/Mini 2
- Garmin Fenix 5/6/7
- Garmin Montana/Oregon
- Garmin Edge cycling computers
- Garmin Connect Mobile (iOS/Android)

**Likely compatible:** Garmin eTrex series, most GPX-capable Garmin devices

### 12.5 Troubleshooting

| Issue | Cause | Solution |
|-------|-------|----------|
| "Invalid GPX file" | Corrupted XML | `xmllint crew_618j.gpx` |
| Waypoints not showing | Symbol not recognized | Use standard symbols: `camp`, `waypoint`, `pin` |
| Track missing elevation | GPX written without `<ele>` | Re-export with `--garmin-include-elevation true` |
| File too large | Too many sample points | `--elevation-sample-interval 200` |
| Timestamps way off | Unrealistic values | Use `--garmin-include-timestamps false` |
